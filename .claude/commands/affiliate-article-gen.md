# /affiliate-article-gen

AOKAEのアフィリエイトサイト向けに、SEO記事を一気通貫で生成する。

## 実行手順

1. **入力の確認**
   `$ARGUMENTS` から以下を取得（不足分は対話）:
   - `--site {site_name}`: 対象サイト（`affiliate_sites` テーブルに存在すること）
   - `--keyword {キーワード}`: メインキーワード
   - `--length short|medium|long`: 800 / 2000 / 4000字（デフォルトmedium）
   - `--intent info|compare|buy`: 記事意図

2. **対象サイトの取得**
   ```sql
   SELECT * FROM affiliate_sites WHERE site_name = '{site_name}';
   ```
   サイト特性（ジャンル、トーン）を把握する。

3. **キーワードリサーチ（簡易）**
   - WebSearch / Firecrawl で検索上位10件のタイトルとH2見出しを収集
   - 共通する「ユーザーの知りたいこと」を5つ程度抽出
   - 差別化ポイント（既存記事が手薄な切り口）を特定

4. **記事構成の生成**
   以下を先に設計してユーザー確認を取る:
   ```
   タイトル案3つ
   メタディスクリプション（120字）
   構成:
   - H2-1: {見出し}
     - H3-1-1: ...
     - H3-1-2: ...
   - H2-2: ...
   ```

5. **本文生成（Haiku）**
   構成確定後、セクションごとにClaude Haikuで本文を生成:
   - 導入: 結論先出し、200字以内
   - 各H2: 400〜800字、具体例 or データを1つ入れる
   - まとめ: CTAを含める（アフィリエイトリンク想定）
   - 読者の次アクションが明確になるように書く

6. **画像プレースホルダー**
   各H2直下に `![画像: {alt text}](TBD)` を入れておく。

7. **保存**
   選択肢を提示:
   - A: `affiliate_sites.drafts` カラム（JSON配列）に追加（スキーマにあれば）
   - B: ローカルに `{site_name}-{slug}.md` として保存
   - C: クリップボードにコピーのみ

## 引数例

```
/affiliate-article-gen --site color-review --keyword "ヘアカラー 発色" --length medium --intent compare
```

## 品質ガード

**必ずチェック:**
- [ ] タイトルにキーワード含有
- [ ] 導入300字以内に結論
- [ ] 各H2が300字以上
- [ ] 同じ表現の繰り返しがない
- [ ] 語尾のバリエーション（です・ます・体言止め）
- [ ] 具体的な数字 or 事例が3箇所以上

**避けるべき表現:**
- 「〜と言えるでしょう」「〜ではないでしょうか」（弱い断定）
- 絵文字の乱用（本文には基本使わない）
- 過度な比較広告表現（景表法リスク）

## コスト

- Haiku: 記事1本あたり ~¥10-30（日本語4000字でも）
- Sonnet/Opus 使用時は明示的にフラグ `--model sonnet` 指定必須

## 注意

- 法律（医薬品、金融、法律）系の記事は **生成拒否**。該当キーワードなら警告してSTOP
- YMYL（Your Money Your Life）系も同様に慎重に
- 生成記事の**ファクトチェックは自動では行わない**。ユーザー側で確認を促す
